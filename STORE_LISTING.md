Name: Force Picture-in-Picture

Summary (max 132 characters, same as manifest description):
Picture-in-Picture for any video, including anime streaming sites. Removes disabled PiP and adds an Alt+P shortcut.

Detailed description:
Force Picture-in-Picture lets you keep a video in a small floating window while you browse, read or work in other tabs.

Many streaming sites, including anime sites like Crunchyroll, mark their video player so that Chrome's Picture-in-Picture button is disabled or missing. This extension removes that mark and keeps it removed if the site adds it back. Press Alt+P on any page with a video to open the player in a floating window, and press it again to close it.

It works on every site and inside embedded players. It collects no data, makes no network requests and asks for no permissions. The source code is on GitHub.

Limits: if a site's player blocks Picture-in-Picture in another way, Alt+P will not open it. Some sites use Alt+P for their own shortcut.
